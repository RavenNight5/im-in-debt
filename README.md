# I'm in Debt - CanJam 2025 (3rd Place)

A short clicker-style game where you spend your attention to pay off debt. Buttons will appear randomly on your virtual computer, pay attention to these and repeatedly press the correct button in order to pass onto the next day.  

<br>

This game was submitted to CanJam 2025: a **small 24 hour game jam** with the theme '**Pay Attention**'.

<br>

The game was worked on by 2 developers and recieved **3rd place**:
